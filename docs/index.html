argsig

One object, two roles, and a more direct approach.
A function and its CLI are no longer separate things.

Zero-dependency · Pure stdlib

argsig is a minimal, zero-dependency decorator that attaches a fully customizable CLI to your plain Python function — without changing the function's calling semantics.

Write the function once, and it seamlessly serves both as a pure, importable Python function and a powerful CLI entry point.

pip install argsig

One Object, Two Roles

import argsig

@argsig.Arg
def add(a: int, b: int) -> int:
    return a + b

add(1, 2)      # Role 1: Plain function → 3
add.run()      # Role 2: CLI entry, parses sys.argv
add.parser     # The CLI projection, fully customizable

Type Hints as CLI Arguments

  • bool → --flag / --no-flag switch
  • list[T] → nargs="*"
  • Literal[...] → argparse.choices (IDE autocompletion + validation)
  • Keyword-only → required=True

Infinite Subcommands

@argsig.Arg
def main(verbose: bool = False): ...

@main.Argument()
def subfoo(): ...

@subfoo.Argument()
def subsubbar(): ...

if __name__ == "__main__":
    main.run()

Shadow Testing

Because run() returns the raw result and never hijacks your function, you can wrap and test a CLI without touching production code:

from main import process
result = process.run()   # capture the true return value

Limitations

  • Requires Python 3.12+ (PEP 695 generic syntax).
  • All parameters must be type-annotated.
  • Positional parameters with defaults only support nargs of None, "?", or "*".
